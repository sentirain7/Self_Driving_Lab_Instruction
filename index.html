연구 체계

8단계 자동 계산 Closed loop

  1. 목표 물성 정의연구자가 목표 물성과 조성 범위 입력
  2. 후보 분자 · 첨가제분자 라이브러리에서 후보 생성
  3. 분자 모델 · 구조 생성벌크 · 층상 · 샌드위치 구조
  4. GPU 분자동역학 계산고성능 GPU에서 자동 실행
  5. 실패 판정 · 재시도평형 · 오류 자동 판정 후 재실행
  6. 물성 · 에너지 추출밀도 · 강도 · 계면 에너지
  7. DB 축적계산 기록 · 원자료 보존
  8. 예측 모델 갱신다음 계산 후보 선택 → 2단계로

목표를 입력한 뒤 2~8단계는 사람 개입 없이 반복됩니다. 예측 모델은 가우스 과정 대리모형이고, 예측 개선 기대가 가장 큰 점을 다음 계산 후보로 고릅니다.

과제 기획 내용

지금의 계산 Closed loop에 로봇 실험과 분석 장비를 더해, 실험 결과로 예측 모델을 다시 학습하고 다음 실험 후보를 고르는 자율실험실을 준비하고 있습니다.

  • 첨가제 후보 가상 스크리닝(GPU · MD · AI)
  • 대리모형 재학습 · 후보 재선별
